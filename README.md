# 小豆苗学习乐园

给孩子使用的语文、数学、英语练习应用，包含小学一至六年级的周计划、专项题包、打卡积分、奖励兑换和家长中心。技术栈为 React、TypeScript、Vite 和 Tailwind CSS。

## 本地运行

本次验证环境为 Node.js 24。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000 。生产构建使用 `npm run build`，预览使用 `npm run preview`。

## 数学解题思路

所有数学题答题前均可点击「不会做？看看解题思路」。先展示方法提示，再由孩子选择是否展开含答案的完整步骤；展开后仍需自己选择答案，下一题默认收起。完整步骤支持中文朗读。

基础计算根据本题数字拆解数数、凑十、退位、分拆相乘等过程；应用题与概念题结合方法提示和题库自带解析。提示逻辑在 `src/lib/mathHelp.ts`，题库在 `src/data/`。

## 一年级奥数自学专区

首页「一年级 · 奥数自学专区」进入，包含 5 个主题共 59 道题：找规律、排队、间隔、有序计数、简单推理。每课 1 道分步互动例题 + 3 道独立练习，支持图解、朗读、求助提示和断点续学。

积分规则：每道新题 2 分努力分，独立答对加 `perCorrect` 分（默认 2 分），学完例题独立做对新题再奖 2 分。同一道题第二次练：努力分 1 分，独立答对加 `perCorrect/2` 分；第三次起每题仍有 1 分努力分。看提示仍有努力分，听题不算求助。重复题积分递减，会优先安排没练过的题。

家长端「奥数自学记录」按主题汇总独立答对、提示后答对和未答对次数，可查看最近一课的逐题记录。

## 英语发音小课堂

首页「英语 · 发音练习」进入，纯学习工具，无积分。

- **音标**：48 个国际音标全覆盖，每个音标配 SVG 侧面口腔图（展示下巴开合、嘴唇圆扁、舌头位置、声带振动）、中文发音提示和 3 个例词。点击例词播放发音。
- **连读**：20 个常见连读短语卡片（如 let us→let's、want to→wanna、going to→gonna），显示原文、连读形式、中文意思、连读规则和例句，支持朗读原句和例句。

## 检查

```sh
npm run check:math
npm run check:thinking
npm run build
npm run lint
```

`check:math` 使用固定随机种子，对全部 278 个数学题包各生成 30 轮，共检查 74,400 道题，其中独立核算 36,958 道纯算式；检查答案存在、选项唯一、解析和思路非空、最简分数、数独有效性及圆柱表面积。此检查不等于逐道审核所有应用题、概念题的教学严谨性。

`check:thinking` 检查 5 个主题 59 道奥数题的答案、选项唯一性、3 步解析完整性、新题优先、求助积分、重复递减、进度保存与幂等结算。

2026-09-20 浏览器验证：390×844 手机尺寸下检查分层提示、查看提示不自动作答、换题收起；完成 9/10 正确的加法题包仅记 1 次、加 38 分；再次完成全对题包后总计 2 次、78 分，刷新后保留。检查在开发 StrictMode 下进行。

本次构建和数学检查通过。全项目 lint 尚有原有 UI 组件、store 混合导出及家长验证随机数相关问题；本次数学题库、思路模块、答题和结果页面通过单独 lint 检查。

## 数据保存

学习记录和积分仅保存在当前浏览器的 localStorage（`xiaodoumiao-v1`），没有云同步。清除浏览器数据会丢失记录。当前记录为每次练习的汇总，不包含逐题错题信息。
